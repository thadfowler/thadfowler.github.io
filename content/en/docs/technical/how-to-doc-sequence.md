## Background

The Good Docs Project knowledge base team developed an onboarding guide to support new contributors. As a member of (and later a co-lead of) the team, I wrote this series to enable readers to:

1. Use GitLab for project management purposes

2. Collaborate effectively with the Good Docs team

In reaching these goals, contributors begin actively participating in Good Docs work to make a real, hands-on impact.
